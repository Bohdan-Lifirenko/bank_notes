**Моделі для визначення PD (Probability of Default).**

---

## 1️⃣ Що таке PD ще раз, одним рядком

**PD** — це **ймовірність того, що позичальник перейде у дефолт протягом певного періоду** (зазвичай 12 місяців).

---

## 2️⃣ Основні типи моделей PD

### 🔹 1. Логістична регресія (найпопулярніша)

📌 **Що це:**
Математична модель, яка перетворює характеристики клієнта у **ймовірність дефолту від 0 до 100%**.

📌 **Чому її люблять банки:**

* проста
* прозора
* легко пояснити регулятору

📌 **Приклад змінних:**

* дохід
* боргове навантаження
* прострочення в минулому
* вік бізнесу

---

### 🔹 2. Скорингові моделі (Scorecard)

📌 **Що це:**
Спрощена форма логістичної регресії, де кожному фактору дають **бали**.

📌 **Результат:**
Сума балів → рейтинг → PD через майстер-шкалу.

📌 **Плюс:**
Дуже зручно для роздрібних кредитів.

---

### 🔹 3. Transition / Migration models (flow-rate)

📌 **Що це:**
Моделі, які оцінюють **ймовірність переходу**:

* з “непростроченого” → “прострочений”
* між різними bucket’ами прострочення

📌 **Ключове слово:**
**flow rate**

📌 **Використання:**

* lifetime PD
* stage 1 → stage 2 → stage 3 (IFRS 9)

---

### 🔹 4. Survival / Hazard models

📌 **Що це:**
Моделі “часу до дефолту”.

📌 **Відповідають на питання:**

> коли з найбільшою ймовірністю станеться дефолт?

📌 **Сильні для:**

* довгострокових кредитів
* іпотеки

---

### 🔹 5. Machine Learning моделі

📌 **Приклади:**

* Random Forest
* Gradient Boosting
* Neural Networks

📌 **Плюси:**

* вища точність

📌 **Мінуси:**

* важко пояснювати
* обмежене використання в регуляторному контексті

---

## 3️⃣ PIT vs TTC у моделях PD

| Тип PD | Що враховує       | Для чого       |
| ------ | ----------------- | -------------- |
| PIT    | Поточну економіку | IFRS 9, ECL    |
| TTC    | Середній цикл     | Basel, капітал |

## 4️⃣ Як виглядає повний ланцюжок

**Дані → модель → скор → рейтинг → майстер-шкала → PD**

### Моделі для визначення ймовірності дефолту (PD)

Ймовірність дефолту (Probability of Default, PD) — це ключовий параметр у моделюванні кредитного ризику, який оцінює шанс, що позичальник не виконає зобов'язання протягом певного періоду (зазвичай 1 рік). Моделі для PD базуються на історичних даних, фінансових показниках, ринкових даних та статистичних методах. Вони класифікуються на кілька типів залежно від підходу: структурні, зменшеної форми, статистичні та моделі машинного навчання. Нижче я детально опишу основні моделі, їх принципи, переваги та недоліки. Для порівняння використаю таблицю.

#### Основні категорії моделей PD

1. **Структурні моделі (Structural Models)**  
   Ці моделі базуються на теорії опціонів і розглядають дефолт як ситуацію, коли вартість активів компанії падає нижче її боргів. Вони використовують ринкові дані, такі як ціна акцій, волатильність та структура капіталу.  
   - **Модель Мертона (Merton Model)**: Визначає PD як ймовірність, що активи фірми стануть меншими за борги на момент погашення. Еквіті компанії моделюється як кол-опціон на активи. Формула для PD: \( PD = N(-DD) \), де \( N \) — кумулятивна функція нормального розподілу, DD — distance to default (відстань до дефолту, \( DD = \frac{\ln(V/D) + (r - \sigma^2/2)T}{\sigma \sqrt{T}} \), V — вартість активів, D — борг, r — безризикова ставка, σ — волатильність, T — час). Ця модель добре ранжує ризики, але недооцінює PD для реальних компаній.  
   - **Модель Moody’s KMV**: Розширення Мертона, яке адаптує модель до реальних даних, враховуючи емпіричні коригування для кращої оцінки. Використовує ринкові дані для розрахунку Expected Default Frequency (EDF).  
   - **Модель Kamakura**: Подібна до KMV, але фокусується на реальних PD з урахуванням кредитних ринків і додаткових факторів, як макроекономіка.  
   Переваги: Теоретично обґрунтовані, використовують ринкові сигнали. Недоліки: Потребують публічних даних (акції), не підходять для приватних компаній.

2. **Моделі зменшеної форми (Reduced-Form Models)**  
   Дефолт моделюється як випадковий процес (наприклад, Пуассонівський), незалежний від структури балансу. Фокус на інтенсивності дефолту (hazard rate).  
   - **Модель Джарроу-Тернбулла (Jarrow-Turnbull Model)**: PD розраховується як \( PD = 1 - e^{-\lambda t} \), де λ — інтенсивність дефолту, t — час. Інтенсивність залежить від зовнішніх факторів (економіка, ставки).  
   Переваги: Гнучкі для моделювання динаміки, підходять для деривативів. Недоліки: Менш інтуїтивні, потребують калібрування на історичних даних.

3. **Статистичні моделі (Statistical Models)**  
   Базуються на регресії та історичних даних про дефолти. Використовують змінні, як фінансові коефіцієнти (борг/капітал, прибуток), макроекономіку.  
   - **Логістична регресія (Logistic Regression)**: Бінарна класифікація: \( PD = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x_1 + \dots)}} \). Змінні: вік компанії, ліквідність тощо.  
   - **Пробіт-модель (Probit Model)**: Подібна до логістичної, але використовує нормальний розподіл.  
   - **Дискримінантний аналіз (Discriminant Analysis)**: Класифікує позичальників за групами (дефолт/не дефолт) на основі лінійних комбінацій змінних, як Altman Z-score.  
   - **Моделі на основі скорингу (Credit Scoring Models)**: Наприклад, FICO score для роздрібних кредитів.  
   Переваги: Прості, інтерпретовані. Недоліки: Припускають лінійність, чутливі до даних.

4. **Моделі машинного навчання (Machine Learning Models)**  
   Використовують алгоритми для обробки великих даних і нелінійних залежностей.  
   - **Випадковий ліс (Random Forest)**: Ансамбль дерев рішень для класифікації.  
   - **Градієнтний бустинг (Gradient Boosting, наприклад XGBoost)**: Покращує прогнози шляхом ітеративного навчання.  
   - **Нейронні мережі (Neural Networks)**: Глибоке навчання для складних патернів, показує високу точність (наприклад, Accuracy Ratio 71%).  
   Переваги: Висока точність, справляються з великими даними. Недоліки: "Чорна скринька", потребують багато даних для навчання.

5. **Інші моделі**  
   - **Моделі виживання (Survival Models або Cure Models)**: Оцінюють час до дефолту, наприклад, на основі nonparametric estimators або kernel methods.  
   - **Гібридні моделі**: Комбінація структурних і ML для кращої точності.

#### Порівняльна таблиця моделей

| Категорія | Модель | Основні змінні | Переваги | Недоліки | Застосування |
|-----------|--------|----------------|----------|----------|-------------|
| Структурні | Merton Model | Вартість активів, волатильність, борг | Теоретична основа, ринкові дані | Потребує публічних компаній, недооцінка PD | Корпоративні кредити, облігації |
| Структурні | Moody’s KMV | Ринкові ціни, емпіричні коригування | Реалістичні PD | Комерційна, залежить від ринку | Банки з IRB-підходом |
| Зменшеної форми | Jarrow-Turnbull | Інтенсивність дефолту, макрофактори | Гнучкість для динаміки | Складне калібрування | Деривативи, портфелі |
| Статистичні | Logistic Regression | Фінансові коефіцієнти, історія | Простота, інтерпретованість | Лінійність, чутливість до даних | Роздрібні кредити, скоринг |
| Машинне навчання | Random Forest / XGBoost | Великі набори даних, нелінійні | Висока точність | Низька інтерпретованість | Сучасні банки, великі дані |
| Інші | Cure Models | Час до дефолту, цензуровані дані | Врахування виживання | Складність | Довгострокові кредити |

Ці моделі регулюються Basel II/III для банків, де PD інтегрується в розрахунок капіталу. Для розробки моделі потрібні дані про дефолти (наприклад, з баз як Credit Benchmark). Якщо ви хочете деталі про конкретну модель, приклади розрахунку чи код (наприклад, в Python), дайте знати!
